# tgs_unfolding

The minimal core of Theory of Geometric Self-Unfolding.

> A system changes in a way that changes what it can later encounter.

## Falsification conditions for TGS itself

TGS would be wrong if:
1. A system that acquires new distinctions through encounter produces no measurable difference in behavior compared to a system that simply accumulates states without changing its distinction space.
2. The minimal experiment produces the same `can_distinguish` result regardless of whether encounters occurred — meaning geometry expansion is an artifact of test design.
3. Any learning system trivially satisfies the TGS criterion. Specifically: if standard supervised learning on labeled data always counts as "self-unfolding," then TGS adds nothing beyond existing learning theory.

The third condition is the most dangerous. TGS must show that not all learning is self-unfolding. The difference: in self-unfolding, the *method of distinction* changes, not just the *content* of what is known. A lookup table that grows is not self-unfolding. A system whose perception structure changes is.
